🏥 LivoCare

AI-powered healthcare application that helps doctors assess NAFLD risk, manage patients, and receive smart clinical insights through medical data and image analysis.

✨ Key Features

👨‍⚕ Patient Management

Register and manage patient records efficiently.

📸 Image Analysis

Upload medical images for AI-assisted diagnosis.

📊 Analytics Dashboard

Track health metrics and patient insights visually.

🧠 Risk Prediction

Real-time NAFLD risk assessment using patient data.

📋 Recommendations

Smart clinical suggestions based on analysis results.

🔐 Secure Access

Protected authentication for healthcare professionals.

Flutter Firebase REST API Bloc Provider Machine Learning
