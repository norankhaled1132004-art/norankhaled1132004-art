🏥 LivoCare

AI-powered healthcare mobile application helping doctors assess NAFLD risk, manage patient records, and generate smart clinical insights through medical data and image analysis.

✨ Key Features

👨‍⚕ Patient Management

Register, organize, and manage patient records efficiently.

📸 Image Analysis

Upload diagnostic images for AI-assisted liver risk assessment.

📊 Analytics Dashboard

Visualize patient insights and health metrics clearly.

🧠 Risk Prediction

Predict NAFLD risk in real-time using clinical indicators.

📋 Smart Recommendations

Provide personalized medical recommendations based on results.

🔐 Secure Authentication

Protected login system for healthcare professionals.

⚙ Tech Stack

Flutter Firebase REST API Bloc Provider Machine Learning
